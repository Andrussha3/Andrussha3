# Обо мне 

## 👨‍💻 Профессиональный профиль

QA-инженер с профильным техническим образованием и практическим опытом обеспечения качества программных продуктов. Специализируюсь на ручном тестировании веб- и мобильных платформ. 

## 🛠 Ключевые компетенции и навыки

* **Виды тестирования:** Функциональное, регрессионное (включая декомпозицию и оценку трудозатрат), кроссбраузерное и мобильное тестирование, тестирование API (REST, SOAP).
* **Инструменты и снифферы:** Postman, Swagger, Charles Proxy, Browser DevTools, Kibana.
* **Мобильное тестирование:** Xcode, Android Studio (чтение логов, сборка и деплой на iOS/Android устройства).
* **Управление и контроль версий:** Jira, TestRail, Git, GitHub.
* **Базы данных:** SQL (SELECT, JOIN, WHERE, агрегатные функции, работа с SQLite).

## 💻 Языки программирования

* **Python:** Средний уровень (использование Selenium WebDriver, автоматизация рутинных задач).
* **C#, Java, JavaScript:** Базовый уровень (понимание архитектуры, чтение кода).

## 💼 Практический опыт и портфолио

### Коммерческий и практический опыт
* Проведение функционального и регрессионного тестирования UI-модулей и веб-платформ (в т.ч. проверка SEO-оптимизации и фильтрации индексации страниц).
* Тестирование мобильных приложений, перехват сетевого трафика, проверка совместимости медиаплееров (работа с потоковым видео H.264/AAC).
* Ведение тестовой документации: составление чек-листов, тест-кейсов, детализированных баг-репортов.

### Пет-проекты и учебные работы
* 🤖 **Автоматизация тестирования (Python + Selenium):** [Скрипт для сброса прогресса на Stepik](https://github.com/Andrussha3/stepik-courses-reset_progress) — работа с веб-элементами, формами и сессиями.
* 📱 **Тестирование мобильного приложения (гибридный подход):** [ссылка на репозиторий](https://github.com/Andrussha3/mobile_testing_hybrid) — полный цикл тестирования, включающий ручную проверку, составление тестовой документации (план автоматизации, тест-кейсы, чек-листы, баг-репорты) и разработку автоматизированных UI-тестов на Kotlin + Espresso с Allure-отчетами
